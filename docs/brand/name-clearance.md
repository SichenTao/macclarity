# MacClarity name clearance — 2026-09-02

The original working name `MacScope` was rejected before publication because an active, overlapping macOS system utility already uses it and `macscope.app` belongs to another macOS product.

Working checks for `MacClarity` found no directly overlapping macOS diagnostic product in general web and GitHub search, and `SichenTao/macclarity` was available immediately before creation. This is a practical collision check, not a legal trademark opinion. Recheck before commercial distribution or trademark filing.

Public identifiers:

- Product: MacClarity
- Repository: `SichenTao/macclarity`
- CLI: `macclarity`
- Swift package: `MacClarity`
