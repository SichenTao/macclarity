# MacClarity v0.1.0 — source preview

## English

The first source preview establishes the evidence and safety foundation: a bounded storage scanner, short performance sessions, deterministic rules, stable redaction, an interactive HTML disk flower, a SwiftUI entry experience, and exact authorization contracts. No prebuilt binary is attached because this maintainer environment has no Apple Developer ID identity; build locally with Swift 6.
