ソースプレビュー

MacClarity を導入して試す

macOS 14 以降、Xcode コマンドラインツール、Swift 6 が必要です。

git clone https://github.com/SichenTao/macclarity.git
cd macclarity
./install.sh

最初は合成デモがおすすめです

swift run macclarity demo --output macclarity-demo.html
open macclarity-demo.html

短い読み取り専用診断を実行

swift run macclarity diagnose --path "$HOME" --duration 30 --output report.html
open report.html

Apple の署名と公証を通過した後に、直接ダウンロードできるアプリを提供します。現在はソースからビルドします。

あなたの Mac、あなたの判断

プライバシーを守り、処理前に明確に。

診断はローカルで動作し、利用状況の送信はありません。共有レポートはローカル識別情報を隠せます。提案が操作を自動承認することもありません。
