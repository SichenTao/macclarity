SOURCE PREVIEW

Install and try MacClarity

Requires macOS 14 or later, Xcode Command Line Tools, and Swift 6.

git clone https://github.com/SichenTao/macclarity.git
cd macclarity
./install.sh

Try the synthetic demo first

swift run macclarity demo --output macclarity-demo.html
open macclarity-demo.html

Run a short read-only diagnosis

swift run macclarity diagnose --path "$HOME" --duration 30 --output report.html
open report.html

A signed and notarized app download will be added only after its distribution gate is complete. The current release builds from source.
